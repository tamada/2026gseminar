## :speaking_head: 目的

good first issue を通じてOSS活動を実践する。

## やること

* 次に挙げるプロジェクトに、初学者向けの Issue（good first issue）が受講者数より多く登録されています。そのうちの一つを選択し、解決してください。Issue にはどう修正すれば良いかまで説明されていますので、その通りに修正してください。
  * https://github.com/tamadalab/welfare-time
* 提出はGitHub上のPRとして、Moodleの課題に取り組んでみた感想などを書いてください。その際、PRの番号、GitHubのアカウント名、補足事項に記載されている項目について書いてください。
* 提出されたPRは、玉田がレビューします。
* 締め切り　2026-11-14 (Sat) 13:15
  * 次回のセミナー開始時間まで．

### 補足事項

* AIを使ってもかまいません。その場合、自分が取り組んだ範囲、AIに任せた範囲を明確にしてください。
  * 例えば「コード修正は自分で行い、レビューはAIに任せた。コミット文と PR の文面はAIに草案を書いてもらった」みたいな感じで。
